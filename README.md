FinTrack

A personal finance tracker that helps you manage income, expenses, monthly budgets, and spending habits.

Features

- Add, edit, and delete transactions
- Search and filter transactions
- Monthly budget management with spending alerts
- Expense breakdown by category
- Monthly income and expense charts
- CSV export of transactions
- Data persistence using localStorage

Tech

React, JavaScript, CSS, Recharts, Local Storage

Run locally

npm install
npm start
